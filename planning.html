📋 Lift Planning Workspace

Estimate boom geometry, review simplified building clearance, calculate target placement geometry, and work through a lift-planning checklist.

Important: These tools provide geometric estimates, not lift approval.

📐 Boom Geometry Calculator

Enter any two known values to estimate the third. All dimensions must use metres and the angle must be in degrees. This simplified model treats the boom as a straight line.

Geometry reference: For a straight boom, horizontal radius is related to boom length and angle by trigonometry. Actual hook height may differ from boom-tip height because of the boom head, hook block, rigging, and load arrangement.

🏢 Obstacle Clearance Calculator

Estimate simplified boom-line geometry relative to a building. Enter the horizontal distance from the crane's centre of rotation to the building's near side.

Horizontal distance measured from the crane's centre of rotation.
Used to estimate the far edge. Enter 0 if not known.
Enter the boom pivot elevation above ground. Default is 0 m.
Safety limitation: This is a simplified two-dimensional straight-boom estimate. It does not model the full boom profile, boom deflection, crane configuration, load movement, rigging, slew path, building overhangs, or other obstructions. Do not use it alone to confirm safe clearance.

🎯 Load Placement Calculator

Estimate the straight-line boom length and boom angle needed to reach a target point, such as the top of a building or a point beyond it.

Enter the target elevation measured from ground level.
Measure horizontally from the crane's centre of rotation to the target point.
Optional geometric allowance only; use the approved lift plan to set the actual target elevation.
How to use for a load behind a building: enter the final load target's horizontal radius, not merely the building's near-side distance. This calculator does not determine whether the boom or load can clear the building along the travel path.
