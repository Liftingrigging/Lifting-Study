📐 1. Crane Radius, Height, Boom Length & Angle

For a simplified right triangle, radius is the horizontal side, vertical height is the perpendicular side, and boom length is the hypotenuse. The angle is measured above the horizontal.

Boom length² = Radius² + Height²
Radius = Boom length × cos(angle)
Height = Boom length × sin(angle)
tan(angle) = Height ÷ Radius

Enter any two suitable values. The calculator will solve for the remaining geometry values where mathematically possible.

Geometry limitation: this is a simplified model. Actual crane radius is normally measured horizontally from the crane's axis of rotation to the load line, as defined by the manufacturer. Boom pivot height, boom head position, reeving, deflection, load-line geometry, and configuration can affect the real values. Do not use this result as a load-chart decision.

🏢 2. Preliminary Obstacle-Clearance Estimator

Use this section to check a simplified boom-to-building geometry. The boom is represented as a straight line from its pivot to its tip. The building is represented by a vertical face at a known horizontal distance from the pivot.

Enter all values to estimate the boom-to-building distance.
Important: there is no single universal boom-to-building clearance distance that applies to every lifting operation. The required separation must be established by a competent lift planner using the site conditions, crane and boom movement, load path, deflection, wind, tolerances, and applicable local rules. This simplified calculation checks only a vertical building face in the same plane as the boom. It does not model the load, boom width, swing, building projections, or the full three-dimensional path. Do not use it as the sole basis for authorizing a lift.

📏 3. Geometry Formula Reference

Pythagorean theorem

L² = R² + H²

Where L = simplified boom length, R = horizontal radius, H = vertical rise.

Trigonometry

sin(θ) = H / L
cos(θ) = R / L
tan(θ) = H / R

If radius and height are known, calculate boom length with √(R² + H²), and angle with arctan(H / R). If boom length and angle are known, calculate radius with L × cos(θ) and height with L × sin(θ).
