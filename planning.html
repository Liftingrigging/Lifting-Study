📋 Lift Planning Workspace

Estimate crane geometry, review building clearance, calculate target placement geometry, and complete a planning checklist.

Important: Geometry estimates do not confirm crane capacity or authorise a lift.

📐Crane Geometry Calculator

Enter two known values to calculate a third using an idealised straight-boom model. Height and radius are measured relative to the boom base reference point used for this geometry.

For a straight boom at angle θ above horizontal: vertical rise = boom length × sin θ; horizontal radius from the selected reference = boom length × cos θ. Actual crane range diagrams and load charts govern real configuration and capacity.

🏢Obstacle Clearance Calculator

Estimate boom-line elevation at the building edges and the signed horizontal separation between the roof-level intersection and the building's near edge.

Enter 0 if only the near edge is being checked.
Safety limitation: This simplified model checks a straight line only. It does not model boom profile, boom deflection, load and rigging dimensions, slew path, overhangs, or other obstacles. A positive result is not proof that the lift path is clear.

🎯Load Placement Calculator

Estimate the straight-line boom length and angle needed to reach a target elevation and horizontal radius.

Measure to the final load target from the crane centre of rotation.
Optional geometry allowance. Set the actual target height in accordance with the approved plan.
For a target beyond a building, enter the final target radius, not the near-side building distance. This calculator does not determine whether the boom, hook, rigging, or load clears the building throughout the movement.
