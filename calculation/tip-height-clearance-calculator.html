Tip Height & Clearance Calculator

Crane Geometry & Obstacle Clearance Study Tool

Crane Geometry

Geometry Formulas

Horizontal Radius:
R = L × cos(θ)

Vertical Boom Component:
H = L × sin(θ)

Tip Height:
Tip Height = Pivot Height + H

Minimum Required Tip Height:
Required Height = Obstacle Height + Clearance

Clearance:
Available Clearance = Tip Height − Obstacle Height

How to Use

  1. Enter the boom length.
  2. Enter the boom angle.
  3. Enter the boom pivot height.
  4. Enter the obstacle height if clearance is required.
  5. Enter the required clearance.
  6. Press Calculate.

Clearance Check

The calculator compares the calculated geometric tip height with the obstacle height and required clearance.

Available Clearance = Tip Height − Obstacle Height

Clearance Margin = Available Clearance − Required Clearance

A positive clearance margin means the calculated geometry provides more clearance than the entered minimum.

Important Study Note

This is a simplified geometric calculation. Actual crane tip height, hook height and obstacle clearance must be verified using the specific crane manufacturer's documentation and configuration.

Actual lifting geometry may be affected by boom deflection, jib configuration, hook block, reeving, load position, ground conditions and the crane's operating configuration.

Safety Notice:

This calculator is for study and training purposes only. It must not replace an approved lift plan, manufacturer's load chart, crane operating manual, engineering calculation, competent-person verification or applicable site requirements.
