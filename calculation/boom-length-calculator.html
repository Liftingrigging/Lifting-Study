Crane Boom Geometry Calculator

Right-Triangle Geometry Study Tool

Enter Any Two Values

Enter any two independent values. The calculator will determine the remaining two values using right-triangle geometry.

Basic Geometry

L² = R² + H²

sin(θ) = H / L
cos(θ) = R / L
tan(θ) = H / R

Calculation Formulas

L = √(R² + H²)

R = √(L² − H²)

H = √(L² − R²)

θ = sin⁻¹(H / L)

θ = cos⁻¹(R / L)

θ = tan⁻¹(H / R)

R = L × cos(θ)

H = L × sin(θ)

Possible Input Combinations

Known Calculated
L + R H + θ
L + H R + θ
R + H L + θ
L + θ R + H
R + θ L + H
H + θ L + R

Worked Example

Suppose:

L = 50 m
R = 25 m

Then:

H = √(50² − 25²)
H = √1875
H ≈ 43.30 m

θ = cos⁻¹(25 / 50)
θ = 60°

Important Study Note

This calculator uses ideal right-triangle geometry. Actual crane boom geometry can be affected by the specific crane configuration, boom deflection, jib configuration, hook block, reeving, manufacturer geometry and operating conditions.
