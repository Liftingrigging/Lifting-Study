Radius from Boom Length & Angle

This study calculator determines the horizontal radius and vertical boom component using basic right-triangle geometry.

Formula

R = L × cos(θ)

H = L × sin(θ)

R = horizontal radius component
L = boom length
θ = boom angle from horizontal
H = vertical boom component

Worked Example

Boom length = 50 m

Boom angle = 60°

R = 50 × cos(60°)
R = 25.00 m

H = 50 × sin(60°)
H ≈ 43.30 m

Important Study Note

Actual crane radius, boom tip height, hook height and operating geometry must be verified using the specific crane manufacturer's load chart, operating manual and configuration information.

Factors such as boom deflection, boom angle measurement, jib configuration, reeving, hook block, ground conditions, load position and crane configuration can affect the actual lifting operation.
